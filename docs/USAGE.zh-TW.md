## 安裝

### 方法一 —— 直接用 .exe（Windows，不用安裝）

到 [Releases](../../releases) 下載 `PuzzleSolver.exe`，點兩下就能跑。
這樣就是全部的安裝步驟了。

Windows SmartScreen 可能會警告這是未簽章的執行檔。
按*其他資訊* → *仍要執行*，或是自己從原始碼打包（見下）。

### 方法二 —— 從原始碼執行

```bash
pip install -r requirements.txt
```

```bash
python run.py
```

需要 Python 3.9 以上。Tkinter 是 Python 內建的，不用另外裝。

## 程式畫面

程式開起來有兩種模式，在最上面選。

### 模式：螢幕（自動填答）

從你的螢幕上讀出謎題、算出答案，然後用滑鼠填完。僅限 Windows。

| 控制項 | 作用 |
|---|---|
| **棋盤位置** | 要擷取的螢幕矩形（X / Y / 寬 / 高）。**預設**還原成預設值；**測範圍**顯示會擷取到什麼 |
| **謎題類型** | 保持*自動判斷*即可，除非它猜錯 |
| **速度** | 超急快 / 極快 / 快 / 標準 / 慢 / 最慢。先從標準開始；如果網頁跟不上就調慢。五題填答合計實測：標準 37 秒、快 21 秒、極快 15 秒、超急快 8 秒——但極快與超急快屬於實驗性：漏點會被驗證補點自動修復，Zip 拖曳快過網頁則沒有補救 |
| **預演** | 勾起來的話只會印出計畫，完全不碰滑鼠 |
| **隱藏** | 執行期間把程式視窗縮到最小 |
| **檢查補點** | 填完之後重讀盤面，補上沒填成功的格子 |
| **開始自動解答** | 開始執行 |
| **只求解** | 算出答案並顯示，但不碰滑鼠 |
| **停止** | 立刻中止 |
| **存圖** | 存下擷取到的畫面 —— 回報辨識問題時很有用 |

### 模式：圖片檔

解一張截圖，並把答案畫在上面。完全不碰滑鼠。任何平台都能用。

| 控制項 | 作用 |
|---|---|
| **選擇圖片...** | 選一張截圖 —— 手機或電腦的都可以 |
| **謎題類型** | 通常保持*自動判斷* |
| **開始自動解答** | 求解，並顯示畫在圖上的答案 |
| **另存答案圖片...** | 把答案疊圖存成檔案 |

### 語言

**語言**選單可以把整個介面在 English 與中文之間切換。
你的選擇會被保存下來，下次開啟時沿用。

## 在網頁上自動玩一局

順序跟你直覺想的相反：**先按按鈕，再開題目**。按下**開始自動解答**之後，
程式會開始監看擷取範圍，棋盤一出現在畫面上就立刻求解並填答——你切換頁面
的反應時間完全不會被浪費。

1. 啟動程式，選擇**螢幕（自動填答）**。
2. 第一次建議先做（但非必要）：勾選**預演**，然後按**開始自動解答**、
   切到謎題頁面。它會完整印出打算點哪裡，但什麼都不會碰。
   確認謎題類型與棋盤大小看起來正確之後，再把預演取消勾選。
3. 按下**開始自動解答**。狀態列會顯示「偵測畫面中」。
4. 切到 Chrome、開啟謎題頁面。不要把棋盤捲出畫面外。
5. **把手從滑鼠移開。** 棋盤一出現，它就會接手。

題目已經開在畫面上時才按按鈕也可以——會在不到一秒內偵測到並直接開始，
跟以前的操作方式一樣能用。等待期間隨時可以按**停止**取消
（若視窗被最小化，先從工作列點開它）。

### 執行期間

- 把滑鼠移到螢幕任何一個角落就能中止（PyAutoGUI 的安全機制）。
- 或按**停止**。
- 記錄區會顯示每個階段以及各階段耗時。

### 為什麼開始前要等一秒

為了讓你按**開始自動解答**的那一下先結束，自動化才開始動。
沒有延遲的時候，它開始點的當下你的滑鼠鍵在實體上還壓著，
兩邊的輸入交錯在一起，把盤面填亂了。

### 它怎麼知道要停

填完之後，它會重讀盤面：

- **有幾格是錯的** → 只補點那幾格（前提是**檢查補點**有開）。
- **盤面不見了** —— 被網站的完成畫面蓋掉 → 停止並釋放滑鼠。

這就是為什麼它不會對著一個已經解完的謎題繼續點下去。

## 從截圖求解

1. 對謎題截圖。手機的話用一般的截圖就行 —— 不用裁切，棋盤會被自動找到。
2. 把圖傳到電腦上。
3. 啟動程式，選擇**圖片檔**，然後按**選擇圖片...**。
4. 按下**開始自動解答**。答案會被畫在圖上。
5. 想留存的話按**另存答案圖片...**。

答案疊圖會把太陽月亮畫成太陽月亮、皇冠畫成皇冠、
Zip 的路徑畫成一條線、Patches 的切法畫成外框矩形 ——
這樣你可以直接照著抄過去。

## 命令列

同一套引擎，沒有視窗。**預設就是預演** —— 不加 `--go` 的話什麼都不會動。

解一張圖片檔並存下答案：

```bash
python -m linkedin_games_solver.ui.cli --image screenshot.png --out answer.png
```

預演它在螢幕上會做什麼，完全不碰滑鼠：

```bash
python -m linkedin_games_solver.ui.cli --screen
```

真的執行，速度比預設再慢一點：

```bash
python -m linkedin_games_solver.ui.cli --go --slowdown 2.5
```

只擷取螢幕上的某個矩形：

```bash
python -m linkedin_games_solver.ui.cli --region 700,200,900,900 --go
```

自動判斷錯的時候，強制指定謎題類型與棋盤格數：

```bash
python -m linkedin_games_solver.ui.cli --image shot.png --type queens --grid-size 9
```

謎題代號：`tango`、`queens`、`sudoku`、`zip`、`patches`。

## 出問題的時候

### 顯示「辨識失敗」

這是**好的**失敗 —— 它知道自己讀不出盤面，所以選擇停下來，
而不是憑猜測去填。

1. 按**測範圍**，確認擷取範圍裡有完整的棋盤。
2. 如果棋盤太小，用 `Ctrl` `+` 把頁面放大。
   辨識是針對寬度約 794px 的棋盤校準的，低於 500px 會出現提醒。
3. 按**存圖**然後打開來看 —— 如果棋盤被切掉了，調整 X / Y / 寬 / 高。
4. 如果存下來的圖看起來沒問題，把**謎題類型**明確指定，不要用*自動判斷*。

### 它選錯謎題類型

手動指定**謎題類型**。目前測過的盤面自動判斷都正確，
但新的配色方案還是有可能騙過它。

### 網頁跟不上 ／ Zip 出現「您必須按照數字的順序」

把**速度**調成*慢*或*最慢*。Zip 是用一次連續拖曳填完的，
網頁必須看到指標經過的每一格。

### 它點錯位置

擷取範圍與瀏覽器視窗在「擷取」到「填答」之間不能移動。
執行期間不要捲動頁面或改變視窗大小。

### 有些格子填了、有些沒填

打開**檢查補點**。它會重讀盤面，把沒填成功的格子補點。
如果某一輪補完之後沒有改善，它就會放棄，
這樣才不會把一個大致正確的盤面反覆點回錯的狀態。

### .exe 打不開

如果是你自己打包的，而且死在
`DLL load failed while importing cp_model_helper`，
那是 PyInstaller 漏掉了 OR-Tools 的原生 DLL。用這行重新打包：

```bash
pyinstaller --onefile --windowed --collect-all ortools --name PuzzleSolver run.py
```
